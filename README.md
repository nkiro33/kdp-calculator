# KDP Calculators

Free calculators for Amazon KDP self-publishers:

- **[KDP Royalty Calculator](https://nkiro33.github.io/kdp-calculator/)**: paperback, hardcover and Kindle royalties with 2026 Amazon.com printing costs and the $12.99 Kindle 70% band.
- **[Amazon BSR to Sales Calculator](https://nkiro33.github.io/kdp-calculator/bsr/)**: estimate daily and monthly sales from a book's Best Sellers Rank.

Plain HTML, CSS and JavaScript with no build step and no tracking. The math is shared with [ShelfScout](https://chromewebstore.google.com/detail/shelfscout-kdp-keyword-ni/bdookocpapjagghbckogahnjebljbjmi), a free browser extension that shows these numbers on Amazon search results and book pages.

Not affiliated with or endorsed by Amazon. Sales figures are estimates.
